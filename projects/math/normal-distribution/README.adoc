== Normal Distribution Examples

.References
* https://docs.rs/rand/latest/rand/[rand - Rust^]
* https://docs.rs/rand_distr/latest/rand_distr/[rand_distr - Rust^]

=== Run the examples 1: Sample from a normal distribution

[source, bash]
----
cargo run --bin normal_sample
----

[source,console]
----
$ cargo run --bin normal_sample
...snip...
-0.49 is from a N(0.00, 0.60) distribution
-0.76 is from a N(0.00, 0.60) distribution
-0.36 is from a N(0.00, 0.60) distribution
0.62 is from a N(0.00, 0.60) distribution
----

=== Run the examples 2: Show histogram of samples from a normal distribution

[source, bash]
----
cargo run --bin normal_sample_iter
----

[source,console]
----
$ cargo run --bin normal_sample_iter
...snip...
